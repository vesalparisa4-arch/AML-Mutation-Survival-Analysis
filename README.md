# Cancer Genomics: Somatic Mutation and Survival Analysis in AML
Computational Biomedicine, Tutorial 3. R workflow using the TCGA AML example provided with maftools: mutation frequencies, burden, oncoplots, transition/transversion spectrum, FLT3 visualization, Kaplan–Meier curves and Cox regression by FAB class and FLT3 status.

## Run
Run `Rscript analysis.R` from this folder. The script installs missing packages and retrieves the bundled example data from maftools. The original package included presentation placeholders rather than verified numerical survival results; run locally and inspect `Week3_R_outputs` before publishing. Check course permission.
